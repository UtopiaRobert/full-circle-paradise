# Full Circle Paradise

A static digital naturalist journal presenting Robert Redecker's 2022 permaculture design for Full Circle Farm in Upper Ojai, California.

## Local preview

Extract the entire folder, then open `index.html`. Do not open `index.html` from inside the ZIP archive, because the browser will not be able to load the accompanying CSS, images and JavaScript.

## Publish with GitHub Pages

1. Create a public repository named `full-circle-paradise`.
2. Upload the **contents of this folder** to the repository root. `index.html` must appear at the top level.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select **main** and **/(root)**, then save.

There is no build step, database, plugin system or external font dependency.
